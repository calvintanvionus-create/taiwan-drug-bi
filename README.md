# 臺灣各縣市查獲毒品的時間與地區變化

BI 作業:用警政署公開的毒品案件資料,做一個可互動的網頁,看各縣市查獲毒品的件數與重量如何隨時間、地區、毒品級別與品項變化。

- 網頁:`docs/index.html`(GitHub Pages 發佈;本機也可直接雙擊開啟,需連網載入圖表元件 ECharts 與字型)
- 圖表:ECharts 5.5.0

## 資料來源與期間

- 來源:政府資料開放平臺「[毒品犯罪資料](https://data.gov.tw/dataset/57268)」(dataset 57268),內政部警政署提供,每季初步統計,僅供參考。
- 原始檔:46 個季檔(民國 104 年第 1 季到 115 年第 2 季,即 2015-01 到 2026-06),約 55.6 萬列。
- 發生日期實際涵蓋 2014 年起(少量舊案或登打錯誤更早,網頁併為「2013前」)。
- 欄位:案件編號、案類、發生日期、發生地點、發生場所(三層)、嫌疑犯人數、毒品品項、數量淨重(公克)。

另外下載了兩份補充資料,目前網頁沒有使用:

- `raw/npa_suspects_occupation_sex/`:警察機關查獲毒品嫌疑犯人數,按職業與性別(民國 91 至 114 年,按年)。
- `raw/moj_juvenile_detention/`:法務部少年觀護所在所毒品罪收容人數,按年齡與性別(民國 111 年 1 月至 115 年 8 月,按月)。

## 資料夾結構

| 資料夾 | 內容 |
|---|---|
| `raw/` | 原始檔,原封不動(季檔、補充資料) |
| `etl/` | `etl.py` 清理合併、`validate.py` 驗證、`build_data.py` 產生網頁資料 |
| `data/` | 清理後資料:`drug_cases_<年>.csv`(依發生年份拆檔,UTF-8 with BOM)、`drug_name_mapping.csv`(品項對照表)、`etl_log.json`(各檔去重紀錄) |
| `docs/` | 網頁:`index.html` 與彙總後的 `data.js` |

## 怎麼重跑 ETL

需要 [uv](https://docs.astral.sh/uv/)。套件寫在各腳本開頭的 inline script metadata,不用另外安裝。

```
uv run etl/etl.py          # raw/ -> data/drug_cases_<年>.csv、drug_name_mapping.csv、etl_log.json
uv run etl/validate.py     # 逐檔核對列數與重量,檢查空值,印出每年件數與重量
uv run etl/build_data.py   # data/ -> docs/data.js,並核對件數總和
```

清理規則:

- 日期:民國年(6、7 碼)與西元年(8 碼)統一為西元,產生 `year`、`quarter`、`month`。
- 縣市:「台」統一為「臺」;無法歸入縣市者分為「境外(外國)」「海域」「無法辨識」。
- 品項:同一品項不同寫法合併(例如「依托咪酯」與「依托咪酯(Etomidate)」),對照見 `data/drug_name_mapping.csv`。
- 級別:標示第一級到第四級,查不到的標「未分級」。
- 去重:只刪同一檔內 10 個原始欄位完全相同的列(共 4,578 列)。
- 重量:原檔皆為公克,輸出 `weight_g` 與 `weight_kg`。

## 限制說明

- 「件」是「案件 × 毒品品項」一筆紀錄,一個案件查到兩種毒品算兩件,不等於去重後的案件數。
- 約一半紀錄(284,548 列)重量為 0,可能是未秤重或未登記;重量指標已排除,件數指標全數計入。
- 毒品級別依現行(2026)分級,不是案發當時的級別;只標了約 40 個有把握的品項,其餘 9,941 列為「未分級」。`data/drug_name_mapping.csv` 的 `level_basis` 欄註明依據,部分品項尚未逐項核對公告。
- 去重可能刪到「同案件、同毒品、兩次查獲且資料完全相同」的真實紀錄。
- 約 60 列品項名稱因原檔編碼損失帶有 `?`,以 `name_garbled` 標記,未修復。
- 網頁資料每個縣市只保留件數前 15 名的品項,其餘併為「其他品項」,全國的小品項合計會略低。
- 資料為警政署每季初步統計,正確數字以該署年度刑案統計為準。
